# Introduction Writing Accumulation

This folder stores reusable writing observations learned from reference papers while using `writing-introduction-skill`.

Agents may read and edit Markdown files here when writing or revising Introduction prose. The content is an auxiliary resource only: local reference-paper source material, the current draft, verified project context, and the user's requirements always have higher priority.

## What to Record

- Connective and transition expressions: concession, contrast, progression, cause, consequence, comparison, limitation, emphasis.
- Degree adjectives and degree adverbs used in polished academic prose.
- Other useful adjectives and adverbs for describing methods, gaps, challenges, datasets, evidence, and contributions.
- Reusable academic sentence patterns that can be adapted without copying distinctive wording.
- Introduction writing logic, such as how papers move from background to gap, from gap to method motivation, or from limitation to contribution.

## Recording Rules

- Prefer short phrases, sentence patterns, and concise paraphrased observations.
- Note the source paper title or filename when available.
- Do not copy long passages from reference papers.
- Keep entries organized enough that future agents can quickly scan and reuse them.
