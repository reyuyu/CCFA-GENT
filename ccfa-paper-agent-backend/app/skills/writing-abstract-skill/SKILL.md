# AbstractSkill

Use this skill for writing, revising, shortening, or strengthening paper
abstracts.

## Inputs To Inspect

- Current abstract, if available.
- Introduction problem/gap, method overview, and main contributions.
- Experimental result summaries, datasets, metrics, and key empirical evidence.
- Target venue or journal style, if provided.

## Required Reasoning

1. Identify the abstract structure: background/problem, gap, method, results,
   and contribution/impact.
2. Ensure every abstract claim is supported elsewhere in the project context.
3. Compress without losing the central problem-method-result chain.
4. Keep terminology aligned with the title, Introduction, and Method sections.

## Writing Constraints

- Do not introduce new claims absent from the manuscript context.
- Do not include implementation details unless central to the contribution.
- Avoid citation markers in the abstract unless the target style requires them.
- Keep the abstract concise, concrete, and venue-appropriate.
- Avoid inflated impact language.

## Output Expectations

- Produce one coherent abstract unless the user asks for variants.
- If evidence is insufficient for result sentences, write cautiously or state
  what result information is missing.
- For patching: replace only the abstract section unless explicitly asked otherwise.
